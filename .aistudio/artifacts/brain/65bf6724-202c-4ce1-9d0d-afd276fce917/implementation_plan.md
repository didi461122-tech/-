# מרתון הישרדות ומפת מסעות התנ"ך האינטראקטיבית

תוכנית יישום להוספת שני רכיבי עומק מרכזיים באפליקציית חידוני התנ"ך: **מצב מרתון הישרדות** (Survival Marathon Mode) עם פסילות, רצפי הצלחה (Streaks) וטיימר מאיץ; ו**מפה אינטראקטיבית של מסעות ואתרי התנ"ך** (Interactive Biblical Atlas) המשלבת המחשה גאוגרפית, ציוני אירועים, פסוקים מקוריים ואתגרי ידע על גבי המפה.

---

## החלטות משתמש ונקודות מפתח

> [!IMPORTANT]
> החלטות שהתקבלו על בסיס העדפות המשתמש בשלב הראיון:
> 1. **מצב משחק חדש**: נבחר **מרתון הישרדות (Survival Marathon)** – מצב מאתגר של מענה על שאלות ברצף עם 3 פסילות (לבבות), מכפילי ניקוד לקומבו, קושי עולה וטבלת שיאים מקומית.
> 2. **כלי עזר פדגוגי**: נבחרה **מפה אינטראקטיבית של מסעות ואירועי התנ"ך** – אטלס חזותי עשיר עם מסלולי מסעות (מסעות אברהם ויעקב, יציאת מצרים והמדבר, כיבוש הארץ עם יהושע, בריחת דוד משאול, אליהו בהר הכרמל), נקודות ציון גאוגרפיות, פסוקים מלווים ומבדקי ידע ממוקדי מפה.

---

## 1. סקירה ותפיסת המוצר (Overview & Core Concept)

### מה נוסף למערכת?
1. **מרתון הישרדות (Survival Marathon Mode)**:
   - השחקן מתחיל עם 3 פסילות (לבבות).
   - כל תשובה נכונה מעלה את רצף ההצלחות (Streak), מגדילה את מכפיל הנקודות ($\times 1, \times 1.5, \times 2, \times 3$), ומאריכה את המשחק.
   - השאלות מתקדמות בהדרגה מרמת קל לבינוני וקשה.
   - טיימר דינמי המתקצר ככל שהרצף עולה, ומעצים את הריגוש.
   - תיעוד שיא אישי (High Score) ורצף שיא (Longest Streak) מקומיים עם חגיגת ניצחון וסיום מכובד.

2. **מפת מסעות ואירועי התנ"ך (Interactive Biblical Atlas & Map)**:
   - מפה וקטורית עשירה ומעוצבת של ארץ ישראל והמזרח הקדום (הסהר הפורה, מצרים, סיני, כנען/ארץ ישראל, מסופוטמיה).
   - סינון לפי תקופות ומסעות מרכזיים:
     - מסעות האבות (אברהם: מאור כשדים וחרן עד שכם, חברון וירושלים; יעקב: בית אל, פדן ארם, נחל יבוק).
     - יציאת מצרים ומסע המדבר (רעמסס, ים סוף, הר סיני, קדש ברנע, נבו).
     - כיבוש ונחלות (ירדן, יריחו, העי, גבעון, עמק איילון, שילה).
     - ימי המלוכה ובריחת דוד (עין גדי, מערת עדולם, גת, ירושלים, הגלבוע).
     - נביאים וניסים (אליהו בהר הכרמל ובאר שבע, יונה ביפו).
   - לחיצה על נקודת ציון פותחת כרטיס מידע מפורט עם הפסוק המקורי, הסבר היסטורי-גאוגרפי, וחידת ידע אינטראקטיבית המשובצת ישירות באותה נקודה.
   - מצב "אתגר המפה": משימת איתור מקומות על פי פסוק (למשל: "איפה אמר דוד: 'הרי בגלבוע אל טל ואל מטר עליכם'?").

## 2. חוויית משתמש ועיצוב ויזואלי (User Experience & Visual Design)

### א. מסך מרתון הישרדות (Survival Mode View)
- **סרגל עליון דרמטי**:
  - 3 לבבות מלאים שהופכים לאפורים/שבורים בעת טעות עם אנימציית רטט עדינה.
  - מד רצף (Streak Meter) עם זוהר עדין (Combo x2, Combo x3).
  - טיימר פעימה ויזואלי ומספרי (`font-mono tabular-nums`).
- **כרטיס השאלה**:
  - טיפוגרפיה ברורה וקריאה מותאמת עברית (`Plus Jakarta Sans` / גופן מערכת עברי נקי).
  - 4 אפשרויות בחירה ברוחב מלא, עם משוב מיידי (ירוק להצלחה, אדום לטעות עם חשיפת התשובה הנכונה והפסוק).
- **מסך סיכום מרתון**:
  - הצגת הניקוד הסופי, מספר התשובות הנכונות ברצף, השוואה לשיא האישי (New Record!), ופירוט הפסוקים של השאלות שבהן טעה השחקן ללמידה מעמיקה.

### ב. מסך מפת התנ"ך (Biblical Atlas View)
- **חלוקת אזור עבודה (Two-Zone Split)**:
  - **70% אזור תצוגת מפה**: בד קנבס וקטורי אינטראקטיבי עם אפשרות זום (Zoom) וגרירה (Pan), קווי גובה ואגמים טבעיים (הכינרת, ים המלח, נהר הירדן, הנילוס, נהר פרת), וסמני מקומות זוהרים לפי שכבות.
  - **30% סרגל מידע ומסעות**: בורר מסעות (מסע אברהם, יציאת מצרים, כיבוש הארץ, דוד המלך), רשימת תחנות כרונולוגית, והצגת כרטיס המיקום הנבחר עם פסוקי המקור.
- **פלטת צבעים מוקפדת (60-30-10)**:
  - 60% רקע מפה בגוון קלף עתיק נקי ונעים לעין (`#FDFBF7` / Dark: `#0F172A`).
  - 30% קווי מים, הרים וגבולות עדינים בכחול ים המלח (`#0284C7`), אדמת מדבר זהובה וטקסט קריא וניטרלי.
  - 10% נקודות ציון פעילות וסמני מסלול בצבעי ברונזה/זהב מלכותי (`#D97706`) וטורקיז מקראי (`#0D9488`).
- **ללא סופרלטיבים או גאדג'טים מיותרים**: כפתורי ממשק מדויקים בעברית פשוטה ("חזרה לראשי", "התחל אתגר מפה", "הבא", "הצג פסוק").

## 3. ארכיטקטורה טכנית ומבנה הנתונים (Technical Architecture)

```
┌────────────────────────────────────────────────────────────────────────┐
│                                App.tsx                                 │
│    (appState: 'home' | 'game' | 'survival' | 'bible_map' | ...)        │
└───────────────┬────────────────────────────────────────┬───────────────┘
                │                                        │
                ▼                                        ▼
┌───────────────────────────────┐        ┌───────────────────────────────┐
│     SurvivalMarathonGame      │        │        BiblicalMapAtlas       │
│  - 3 Lives / Strike Engine    │        │  - Vector Map Canvas          │
│  - Dynamic Streak Multiplier  │        │  - Journey Path Polylines     │
│  - Adaptive Timer & Questions │        │  - Location Pins & Details    │
│  - Local High Score History   │        │  - Map Quiz Challenge Mode    │
└───────────────┬───────────────┘        └───────────────┬───────────────┘
                │                                        │
                ▼                                        ▼
┌───────────────────────────────┐        ┌───────────────────────────────┐
│     survivalService.ts        │        │      biblicalMapData.ts       │
│  - High scores in localStorage│        │  - Coordinates & Region nodes │
│  - Score calculation rules    │        │  - 5 Major Historical Journeys│
│  - Streak milestone awards    │        │  - Verses, Quizzes & Context  │
└───────────────────────────────┘        └───────────────────────────────┘
```

### מבני נתונים עיקריים

1. **BiblicalLocation & BiblicalJourney** (`src/types/bibleMap.ts`):
   - `id`: מזהה ייחודי (למשל: `hebron`, `jerusalem`, `shiloh`, `mount_carmel`).
   - `name`: שם המקום המקראי (למשל: "חברון - מערת המכפלה").
   - `modernName`: זיהוי גאוגרפי בן זמננו.
   - `coordinates`: יחסי $x, y$ או קואורדינטות קנבס למיקום מדויק באטלס.
   - `region`: חבל ארץ (יהודה, שומרון, גליל, עבר הירדן, סיני, מצרים).
   - `verses`: רשימת פסוקים רלוונטיים (ספר, פרק, פסוק, טקסט).
   - `historicalSummary`: תקציר היסטורי תמציתי.
   - `quizQuestion`: חידת אתגר ממוקדת מקום.

2. **SurvivalState** (`src/types/quiz.ts`):
   - `lives`: מספר פסילות נותרות (3 עד 0).
   - `currentStreak`: רצף תשובות נכונות נוכחי.
   - `bestStreak`: רצף שיא במשחק הנוכחי.
   - `score`: ניקוד מצטבר מבוסס זמן וקומבו.
   - `multiplier`: מכפיל נקודות ($\times 1$ עד $\times 3$).

## 4. תוכנית ביצוע מפורטת (Implementation Steps)

1. **יצירת מודלי נתונים ומאגר המפה (`src/types/bibleMap.ts`, `src/data/biblicalMapData.ts`)**:
   - הגדרת טיפוסים למקומות, מסלולים, ותחנות.
   - כתיבת מאגר של לפחות 20 אתרים תנ"כיים מרכזיים ו-5 מסעות היסטוריים מפורטים עם פסוקים מנוקדים, הסברים ושאלות מפה.

2. **בניית קומפוננטת מפת התנ"ך (`src/components/BiblicalMapAtlas.tsx`)**:
   - מפת ארץ ישראל והאזור בגרפיקה וקטורית אינטראקטיבית חדה.
   - שכבת קווי מסלול (SVG Paths) מונפשים ברכות בעת בחירת מסע.
   - סיכות מיקום לחיצות, פופ-אפ עשיר עם פסוק והסבר, ואפשרות להפעלת "אתגר חידון המפה".

3. **בניית קומפוננטת מרתון הישרדות (`src/components/SurvivalMarathonGame.tsx`)**:
   - מנוע המשחק עם 3 לבבות, אנימציות הצלחה ופסילה.
   - טיימר מותאם אישית שמתקצר עם כל 5 שאלות נכונות ברצף.
   - חישוב תוצאה סופית, הצגת שיאי עבר אישיים ושמירה ב-`localStorage`.

4. **שילוב במסך הבית ובניווט הראשי (`src/components/HomeScreen.tsx`, `src/App.tsx`)**:
   - הוספת כרטיס ייעודי למרתון הישרדות בבורר מצבי המשחק.
   - הוספת כפתור גישה בולט בראש מסך הבית ל"מפת התנ"ך האינטראקטיבית".
   - עדכון ניווט ה-`appState` לתמיכה במצבים החדשים בצורה חלקה ועם תמיכה מלאה ברטט, צלילים וחזרה למסך הבית.

5. **בדיקות ואימות מלא (`compile_applet`, `lint_applet`)**:
   - וידוא קומפילציה ללא שגיאות TypeScript, ריצה נקייה ב-Vite, ותאימות מלאה ל-RTL ולכל גדלי המסכים (דסקטופ ומובייל).
